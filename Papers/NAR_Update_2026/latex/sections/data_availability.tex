\section{Data Availability}

The ModelSEED biochemistry database is freely available without registration or
login at \modelseedurl{}, and the underlying data are distributed through the
following channels.

\begin{itemize}
  \item \textbf{GitHub repository:} \repourl{}, tagged as \texttt{v2.0.0} for the
        2026 release.
  \item \textbf{PyPi package:} \TBD[\texttt{modelseed-biochem==2.0.0}].
  \item \textbf{Solr REST endpoint:} retained from the 2020 release.
  \item \textbf{Web interface:} the ModelSEED website (\TBD[final URL]) has been
        updated to include atom-mapping-aware reaction landing pages. KBase
        integration is retained.
  \item \textbf{Atom mapping endpoint:} \TBD[delivery mechanism from the
        Nikoloski collaboration].
  \item \textbf{Continuous integration:} a GitHub Actions workflow at
        \file{.github/workflows/} runs on every PR to \texttt{dev}.
  \item \textbf{License:} Creative Commons Attribution, matching the 2020
        release; data derived from KEGG and MetaCyc remains subject to those
        databases' licenses.
\end{itemize}
